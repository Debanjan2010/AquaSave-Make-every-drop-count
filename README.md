# AquaSave

AquaSave is a small, single-file household water-saving prototype. It uses plain HTML, CSS, and JavaScript—no npm install, development server, or build step is needed.

## Open the website

1. Open the `mayank` folder.
2. Double-click `index.html` to open it in your browser.

The calculator and rain-tank illustration work offline. Weather search needs an internet connection. Device location is optional and requires browser permission; if it is unavailable, search by town instead.

## What is included

- Household water-use and savings estimate
- Interactive rainwater tank illustration
- Optional local forecast and three-day outlook
- Responsive layout and keyboard-friendly controls

All savings are estimates, not utility readings or guaranteed results. Weather is provided by Open-Meteo.
